# Andr-Saenz-Benedetti
📦 Análise Logística - Loggi
Este projeto tem como objetivo realizar uma análise logística da empresa Loggi, utilizando dados reais ou simulados para entender aspectos como desempenho de entregas, rotas, tempos de entrega, distribuição geográfica e eficiência operacional.

🏢 Sobre a Loggi
A Loggi é uma startup brasileira de logística que conecta entregadores autônomos a empresas e consumidores por meio de uma plataforma tecnológica. Focada em eficiência, a empresa atua com entregas rápidas, especialmente em centros urbanos.

🎯 Objetivos da Análise
Avaliar tempo médio de entrega por região ou tipo de serviço

Identificar rotas mais eficientes e mais críticas

Mapear atrasos, gargalos logísticos e anomalias

Gerar visualizações interativas para tomada de decisão

Propor melhorias operacionais com base nos dados

🧩 Dados Utilizados
Dataset simulado/real com as seguintes colunas:

ID da entrega

Cidade/UF

Data e hora de coleta e entrega

Distância percorrida

Tipo de pacote

Nome do entregador (ou código)

Status da entrega (no prazo, atrasada, etc.)

🔒 Nenhum dado sensível ou privado é divulgado neste projeto.

🛠️ Tecnologias e Ferramentas
Python 3.x

Pandas e NumPy

Matplotlib / Seaborn / Plotly

GeoPandas (para mapas)

Scikit-learn (se houver clustering, previsão, etc.)

Streamlit (opcional para dashboard interativo)

📈 Etapas da Análise
Importação e limpeza de dados

Análise descritiva (estatísticas gerais)

Visualizações temporais e geográficas

Estudo de atrasos e tempos médios

Análise de clusterização de regiões (opcional)

Geração de insights e recomendações
